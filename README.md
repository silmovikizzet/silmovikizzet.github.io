# Static Portfolio

Static portfolio ready for GitHub Pages and future CMS integration.

## Customize

Search and replace:

- `YOUR NAME`
- `Your Name`
- `USERNAME`
- `you@example.com`
- placeholder project / experience / certification text

Add CV:

`files/cv.pdf`

## Preview locally

```bash
python3 -m http.server 8000
```

Open:

`http://localhost:8000`

## Deploy

```bash
git add .
git commit -m "Add static portfolio"
git push
```
